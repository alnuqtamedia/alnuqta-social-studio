# Alnuqta Social Studio

استوديو مستقل لإنتاج تصاميم ومحتوى السوشيال ميديا لمنصة النقطة.

## النسخة المعتمدة

الرابط العام المعتمد: https://alnuqta-social-studio.vercel.app/

واجهة ثابتة تُبنى بأمر `npm run build` إلى `dist`، مع إعداد Vercel في
`vercel.json`. لا توجد خدمة رندر فيديو على الخادم. ملفات GitHub Pages
وCloudflare وNetlify باقية كتكوينات بديلة/تاريخية؛ وجودها لا يثبت أنها الوجهة
المعتمدة. لا تغيّر الوجهة أو الأسرار اعتماداً على توثيق قديم.

## البنية والميزات

- قوالب Carousel، ريلز/ستوري، يوتيوب، وتصميم خبر بصورة ونص وهوية النقطة.
- إدخال نص أو PDF نصي: استخراج PDF محلي بواسطة PDF.js؛ الصور الممسوحة تحتاج OCR خارج هذه النسخة.
- تسجيل الأمر الصوتي اختياري بموافقة؛ الأمر المفرغ يُراجع قبل التنفيذ.
- السرد متصل، مع وسائط متعددة وفحص صلتها، وعناوين ورسوم وسبتايتل تقديري.
- التصدير عبر Canvas وMediaRecorder داخل الجهاز. أبقِ الصفحة ظاهرة أثناء الرندر.
- المشاريع تحفظ في IndexedDB داخل المتصفح نفسه؛ استخدم نسخة ZIP للنقل والنسخ الاحتياطي.
- تنزيل الملفات والنشر اليدوي؛ لا يوجد نشر تلقائي إلى الشبكات الاجتماعية أو الموقع.

## الاتصال الحالي

الواجهة تستخدم مشروع Supabase المشترك مع الموقع الإخباري، والمحدد في
`public/preview-config.js`. استقلال المستودعين لا يعني انفصال الخلفية.
مسار الإنتاج الحالي في `public/studio-production.js` يستدعي:

- `gemini-studio-preview`: التخطيط والتصحيح وفحص الوسائط وضبط السرد.
- `gemini-tts-preview`: التعليق الصوتي.
- `pexels-search-preview`: البحث عن الوسائط.

بعض أدوات الواجهة القديمة تستدعي دوال `gemini-studio` و`gemini-tts`
و`pexels-search` و`gemini-image`؛ لا تحذفها قبل تتبع المستهلكين.
الدوال المنشورة هي المرجع للحالة التشغيلية؛ نسخ `backend` و`supabase/functions`
لا تعني تلقائياً أن كل الملفات المحلية منشورة.

## الأمان

المفاتيح الخاصة تبقى في Supabase Secrets. مفتاح anon العام ليس مفتاحاً خاصاً
ولا يمثل تسجيل دخول شخصي. الدوال الحالية تطبق قائمة Origin وحد طلبات
لكل دالة وبصمة شبكة. Origin قابل للمحاكاة خارج المتصفح؛ هذه الحماية لا تعادل
دعوات مستخدمين أو حسابات دخول للاستوديو. لا تعطل JWT أو تفتح Origins لمعالجة
خطأ في التوليد، ولا تعدّل حماية غرفة الأخبار ضمن شغل الاستوديو.

## الفيديو والتوافق

يختار مسار المعاينة MP4 إذا دعمه المتصفح، وإلا WebM مع امتداده الحقيقي.
نجاح قياس المدة والتزامن لا يثبت قبول الملف في Instagram أو WhatsApp.
إعادة تسمية WebM إلى MP4 ليست تحويلاً. حدود الاستخدام الحالية تصل إلى
600 ثانية؛ الذاكرة وحالة الصفحة ودعم الترميز تحدد النجاح على الجهاز.

الانتقال الحالي مزج مع إطار من نهاية المشهد السابق، وليس تشغيل فيديوهين
متداخلين بالكامل. توقيت كلمات السبتايتل تقديري؛ يلزم الاستماع والمشاهدة.
اختبارات القبول العملية في [docs/export-acceptance.md](docs/export-acceptance.md).

## التطوير والتحقق

```bash
npm ci
npm test
python3 -m http.server 8000 --directory dist
```

التشغيل المحلي يحتاج Origin مسموحاً به في إعدادات الدوال؛ لا تفتح القائمة
للجميع. الاختبارات لا تستهلك Gemini ولا تثبت توافر الحصة أو جودة الصوت الحي.
قبل إصدار يمس الفيديو: اختبر 45 ثانية عمودي و120 ثانية أفقي، حفظ واسترجاع
ZIP، وإلغاء الرندر؛ قِس الملف الناتج واستمع إليه كاملاً.
