# المرحلة الأولى — كود تجريبي، غير منشور

أضيفت ثلاثة قوالب إلى StudioMotion.draw، وهو مسار Canvas المستخدم في الإنتاج: اقتباس حرفي من التعليق مع إسناد المحرر؛ مقارنة رقمين غير سالبين بوحدة مشتركة وخط أساس صفري؛ إبراز مستطيل في مشهد وثيقة بإحداثيات الصورة النهائية. لا يقوم البرنامج بتوثيق المصدر أو صحة القيم تلقائياً.

تحت خيار الرسوم المتحركة توجد بطاقة «إخراج المشهد». اختر رقم المشهد، حمّل إعداداته، اختر القالب وأدخل البيانات ثم طبّق. اختيار الإخراج المعتاد يزيل creative من المشهد. تغيير القالب يبطل المعاينة السابقة ويتطلب معاينة جديدة. لا تُغير هذه الأدوات التعليق أو الصوت أو الوسائط.

الاقتباس محصور في 180 حرفاً ومطابقة نصية مع التعليق؛ المقارنة في الواجهة رقمان فقط؛ إبراز الوثيقة يحدد كنسب مئوية من Canvas النهائي وليس من الصورة الأصلية، لذلك يجب مراجعته إذا تحركت الصورة أو تغير القص. الطمس التتبعي غير منفذ. أضيف مسار محلي للأوامر العربية المحددة للاقتباس والمقارنة وإزالة القالب. الأوامر العامة تبقى بمسار Gemini المعتاد. لم يُفعّل اختيار حر تلقائي للقوالب من Gemini.

مهم: docs/creative-capabilities.json وcreative-direction-ar.md وثيقتا تخطيط المرحلة السابقة، وليستا سجل القدرات المستخدم وقت التشغيل. حالة planned فيهما لا تعني أن قوالب هذه المرحلة مفعّلة في الإنتاج.

التحقق المنفذ داخل بيئة JavaScript المتاحة: تحليل الوحدتين نحوياً؛ 7 فحوص تحقق للقوالب؛ 18 حالة رسم بمحاكاة Canvas للاتجاهين وأزمنة مختلفة، مع إحداثيات عددية وحفظ شفافية السياق. هذا لا يفحص البكسلات والخطوط أو DOM أو ملف الفيديو. أضيف scripts/test-creative-overlays.mjs إلى npm test، وشُغّل npm test كاملاً مع build وفحص الحزمة بنجاح عبر GitHub Actions على commit 3de9eef3ef81101029f2cdc3afb6ebd9d0499221. لم يُفحص المتصفح أو الفيديو بصرياً. أضيف لاحقاً اختبار تطبيع بيانات القالب وحفظها واستعادتها، ويُتابع فحص أحدث commit بشكل مستقل.

قبل الدمج: تشغيل npm test، اختبار عناصر التحكم والحفظ والاستعادة، فحص عمودي وأفقي مع أرقام صفرية وعناوين طويلة ومشهد وثيقة، وفحص فيديو مصدّر وصوت ومدة وتزامن. التأكد أن حقول creative تحفظ في النسخ وأن تحديث المشاهد من Gemini لا يحذفها أو يغيّر معنى بياناتها دون مراجعة. لا يُعلن نجاح الإنتاج حتى ذلك.

لا تنزيل لمكتبات خارجية ولا تعديل للموقع الإخباري أو الأسرار أو موفر الصوت. الفرع مسودة؛ لا نشر تلقائي مقصود.
