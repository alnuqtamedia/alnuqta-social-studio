# الإخراج التلقائي مع Gemini

اكتب طلبك الطبيعي مع المادة، مثلاً: «حوّل هذا التقرير إلى فيديو وثائقي هادئ، اختر الحركات والانتقالات والتلوين المناسب لكل مشهد». يخبر مخطط Gemini الآن محرك العرض بإعدادات cinema مباشرة. الاقتباس الآلي يحتاج نصاً حرفياً واسم مصدر موجودين في المادة والتعليق. لا تحتاج الأوامر المحلية ذات الصيغة الثابتة.

الحركات والتلوين والانتقالات والعناوين والترجمة والأيقونات متاحة. المقارنات الرقمية وتحديد موضع وثيقة تبقيان ببيانات يحددها المحرر؛ لا يتم اختراع بيانات أو إحداثيات. الموسيقى والمؤثرات الصوتية الخارجية غير مضافة بهذه المرحلة. «بلا مؤثرات» يطلب static/natural/cut. الاختيارات اليدوية تبقى قابلة للتعديل. فتح مشروع محفوظ لا يشغل Gemini أو يغيّر مشاهد المشروع.

التحقق: اختبار handler الحقيقي مع Gemini وهمي، مرور البيانات إلى مطبّع محرك العرض، رفض الاقتباس غير المدعوم، حماية الوثائق، سلامة المشاريع القديمة. جودة اختيار النموذج الفنية تعتمد على المادة والطلب وتحتاج مراجعة المعاينة. لم يستعمل الاختبار API مدفوعاً.
