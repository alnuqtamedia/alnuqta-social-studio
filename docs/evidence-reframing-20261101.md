# Exact reference import and automatic illustrative reframing

The user's six-scene Nanni report still held scenes 2 and 5 for location review. A scene labelled as the actual tablet could pass with unrelated Pexels stock. Recovery explicitly skipped location-review scenes, and the existing Commons adapter rejected the upstream thumbnail host and requested a thumbnail width that now returns HTTP 400.

Changes:
- Named originals require an exact reference binding and an explicit identity-match verdict, independently of geographic context. Existing misleading stock is retained as unused media, not used as evidence.
- Resolve a supplied Wikimedia Commons File URL through the fixed official API. Accept only JPEG/PNG/WebP and approved licenses. The reference must also pass source-description and visual review. A small curated lookup supplies the previously researched Ea-Nasir tablet when its story is identified. This is not a universal artifact catalog.
- Support the official thumb.wikimedia.org host and 250px previews. Live API/image fetch verified the actual tablet and photographer Joel Bellviure, CC BY 4.0. License credit text accompanies video downloads for the publication description; it is not silently discarded.
- Held illustrative scenes get one bounded editorial reframe, keeping narration and successful scenes. The model can choose concrete neutral details or reuse an already bound original when it supports the statement. It cannot invent reference IDs or rewrite the script. Specific documents, portraits, events and strict video requests are not silently replaced with graphics.
- The original reference is shown with contain framing; a reused reference can be shown as a detail. This does not claim a new shot of its museum.

Verification includes the full npm suite, a six-scene controller regression, a browser fixture export with video/image/video coverage and decoded MP4 frames, malicious-host/URL tests and source identity guards. Browser fixtures use synthetic images, tone and model verdicts; they test the application flow, not live editorial judgment. Live reference resolution is tested separately. No news site, branding, API secret or saved-project DB migration is involved.
