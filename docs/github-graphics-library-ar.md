# مكتبة GitHub للجرافيك في استوديو النقطة

هذه قائمة مختارة قابلة للتوسّع، وليست ادعاءً بحصر كل GitHub. أربع موارد مدمجة فعلياً في الحزمة الحالية، وبقية الموارد مراجع لتوسعات تحتاج محولات أو محركاً إضافياً. موارد التصميم نفسها لا تحتاج اشتراكاً؛ خدمات Gemini والصوت تبقى وفق حصصها الحالية.

## الاستخدام

من لوحة الإنتاج افتح «مكتبة الجرافيك». اختر حزمة صحفية أو اقتصادية أو استقصائية أو بسيطة، وابحث عن أيقونة بالعربية أو باسمها. لتخصيص مشهد، اختر الأيقونة ثم أدخل عبارة موجودة حرفياً في تعليقه. الرسوم توضيحية، وليست إثبات علاقات أو هويات. أنشئ معاينة فيديو جديدة بعد التعديل. الموارد تعمل محلياً وتُحمّل عند الحاجة، وتحفظ مع إعدادات المشهد. فتح مشروع قديم لا يفعّل الحزمة عليه؛ تطبيقها قرار صريح من المحرر.

المشاريع الجديدة من زر Gemini تعتمد الحزمة تلقائياً، ويُختار القالب الأولي من وصف التقرير وأمر المستخدم. يقترح Gemini الأيقونات والعناوين المرتبطة بالنص ضمن مخططه الموجود، ثم تُرسم باستخدام الموارد المدمجة. التوقيت داخل المشهد تقديري كما هو موضح في تقرير الإنتاج.

## المصدر والثبات

- أيقونات Tabler: نسخة مثبتة بالـcommit، 4808 أيقونات خطية، مع استبعاد شعارات العلامات التجارية، حُوّلت من SVG إلى مسارات Canvas بواسطة scripts/vendor-design-assets.py. لا يتم تشغيل SVG أو HTML من المستخدم. الشيفرات والعدد وبصمات SHA-256 في public/vendor/sources.json.
- Cairo: ملف TTF الأصلي دون تعديل، من مجلد الخط في Google Fonts وبنسخة ثابتة. الرخصة OFL-1.1 بجانب الملف، ويستعمله النمط الجديد باسم CSS محلي StudioCairo.
- D3 Ease وRough.js: توزيعتا npm الرسميتان 3.0.1 و4.6.6 لمشروعي GitHub المذكورين، مثبتتان في package-lock.json مع سلامة الحزم. عملية البناء تنسخ توزيعات المتصفح ورخصها محلياً، بما فيها رخص التبعيات المضمّنة في Rough.
- لا تحميل تلقائياً لكود GitHub متغير أثناء التشغيل، ولا نسخ لمكتبات كاملة غير مستخدمة، ولا تعديل لمفاتيح API أو نماذج الصوت أو الموقع الإخباري.
