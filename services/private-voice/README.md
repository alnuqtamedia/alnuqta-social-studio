# صوت خاص للاستوديو

هذه خدمة مستقلة لتوليد تعليق بصوت صاحب التسجيل باستخدام SILMA. لا تعمل داخل
Vercel أو Supabase Edge. تحتاج مضيف Python يعمل طوال مدة الاستخدام؛ وجود
الكود لا يعني أن الخدمة منشورة أو أن جودة تقليد الصوت معتمدة.

التسجيل المرجعي والمفتاح والنص المطابق تبقى على المضيف الخاص، خارج Git.
الواجهة ترسل نص التقرير إلى هذا المضيف فقط. ملف الصوت الناتج يدخل مسار
المحاذاة والمعاينة والحفظ المعتاد؛ محاذاة Gemini ترسل الصوت الناتج إلى Gemini
كما في المسار الحالي. إعداد الاتصال نفسه لا يُحفظ ولا يصدّر في المشاريع.

## تشغيل Linux CPU

يحتاج Python 3.12 وFFmpeg وgcc وg++، ومساحة لتنزيل نماذج SILMA ومشكل النص
والـvocoder عند أول استخدام. التسريع GPU اختياري؛ لم يُختبر الأداء على
MacBook Air Intel 2017. لا توجد استضافة مجانية دائمة مرفقة بهذا التغيير.

```bash
python3 -m venv .venv
.venv/bin/pip install torch==2.7.1 torchaudio==2.7.1 torchvision==0.22.1 --index-url https://download.pytorch.org/whl/cpu
CC=gcc CXX=g++ .venv/bin/pip install -r requirements.txt
```

الخدمة تستخدم مرجع WAV أحادي القناة 24 kHz بطول 2–8 ثوانٍ، ونصاً مطابقاً
للكلام في المقطع بصيغة UTF-8. لا تستخدم التسجيل الكامل الطويل: المحرك يقصّه
ويعيد تفريغه، وقد يتغير المرجع الذي تسمعه.

```bash
export PRIVATE_VOICE_REFERENCE=/private/voice/reference.wav
export PRIVATE_VOICE_TRANSCRIPT=/private/voice/reference.txt
export PRIVATE_VOICE_TOKEN="$(.venv/bin/python -c 'import secrets; print(secrets.token_urlsafe(48))')"
export PRIVATE_VOICE_DEVICE=cpu
.venv/bin/uvicorn server:create_app --factory --host 127.0.0.1 --port 7861 --no-access-log
```

انسخ المفتاح من إعداد الخدمة الخاص إلى خانة الربط في الاستوديو، وعنوان
`http://127.0.0.1:7861` إذا كان المتصفح والخدمة على الجهاز نفسه. قد يطلب المتصفح
السماح بالاتصال بالشبكة المحلية. للمضيف البعيد استخدم HTTPS خلف reverse proxy
بحد لحجم الطلب 64 KB ومهلة مناسبة، واترك المنفذ الداخلي غير متاح للعامة.
لا تمرّر المفتاح في URL ولا تضف التسجيلات إلى المستودع.

افتح «ربط صوتي الخاص»، أدخل العنوان والمفتاح ثم «اتصال واختيار صوتي».
بعد الاتصال يصبح خيار «صوتي الخاص — مولّد» متاحاً. توليد التعليق يستخدمه
تلقائياً ويحتفظ بمسار ضبط السرد والمحاذاة والموسيقى والتصدير الحالي. الخدمة
تقرأ النص حرفياً؛ تعليمات الأداء الخاصة بأصوات Gemini لا تُمرر إليها.
لا يوجد تبديل تلقائي إلى صوت جاهز إذا فشل صوتك. مهلة الطلب عشر دقائق، مع
إمكانية الإلغاء؛ إلغاء المتصفح لا يوقف عملية الاستدلال التي بدأت على المضيف.

اختبر أولاً جملة قصيرة واستمع للنطق والتشابه. لا تعتمد صوتاً ناقصاً أو ملفاً
لا ينطق النص كاملاً. هذا صوت مولّد من مرجع مرخّص، وليس تسجيل قراءة بشرية جديدة.

## اختبارات

```bash
.venv/bin/python test_server.py
```

تختبر العقود والمصادقة والمدخلات باستخدام محرك وهمي؛ لا تثبت جودة الاستنساخ.
اختبارات الواجهة تدخل ضمن `npm test` في جذر المستودع.

SILMA: https://github.com/SILMA-AI/silma-tts — كود MIT، أوزان Apache-2.0.
